Use it from any device

Once Home says Ready, the console answers on port 8081. The model name in a request is ignored: the loaded one answers.

1Chat OpenAI API
# the address Home shows on the TVPS5=http://192.168.8.53:8081 curl $PS5/v1/chat/completions \  -H 'Content-Type: application/json' \  -d '{"model": "ps5", "messages": [    {"role": "user",     "content": "Hello from my laptop"}]}'
2Decide /v1/systemone
curl $PS5/v1/systemone \  -H 'Content-Type: application/json' \  -d '{"state": "Charged twice. Refund me.",  "questions": {    "intent": {"type": "choice",      "instructions":        "What does the customer want?",      "criteria": {"refund": null,        "information": null,        "cancel": null}},    "angry": {"type": "noul",      "instructions":        "Is the customer angry?"}}}'

Decision models are powered by Ollaya, which runs them on a PC the way Ollama runs language models: one forward pass, no text generated. The Suggested list has d1 Omni 600M, d1 3B and Clef Flash. Claude Code, opencode and codex setups are in docs/CLI.md.

Install

A PS5 on firmware 7.00 to 13.60, jailbroken, with these payloads loaded

PayloadForNeeded
kstuff-liteThe kernel patches homebrew runs onRequired
etaHENHomebrew supportRequired
ShadowMountPlusPuts PS5LM on the home screen from /data/homebrewRequired
elfldrTemperature, power and real free space; full-speed downloads, through the app's own ftpsrvRecommended
ftpsrvInstalling the app, copying models from a PC; downloads write through it when it runsRecommended
  1. 1Downloadps5lm-app-vX.Y.Z.zip from the latest release, and unzip it
  2. 2CopyThe PPSA99575 folder to /data/homebrew over FTP. ShadowMountPlus adds PS5LM to the home screen
  3. 3Get a modelIn Models > Suggested, or copy a .gguf to /data/PS5LM/models or to PS5LM/models on a USB drive
  4. 4Load itOnce Home says Ready, open http://<console>:8081 in a browser, or point your client at it

To update, copy the new folder over the old one: settings, models and downloads stay in /data/PS5LM. If the app says it cannot write to /data/PS5LM, the HEN has not opened storage to it; the fix for each HEN is in the README.

Questions

What people ask before they install it

  • Does it run on the GPU?Yes, every layer. llama.cpp's Vulkan backend runs on RADV, the open Mesa driver, ported to the PS5 by PS5_Vulkan.
  • How big a model can it run?About 11 GB of model and context. Qwen 3.8 27B at 2-bit fits with a 64k context; the planner tells you what fits before you download.
  • Does this run games or need any Sony code?No. PS5LM runs open-weight models and nothing else. No games, keys, firmware or Sony SDK files are part of it.
  • Can it break my console?It writes only to its own folders, never to system files. Under a long load it runs warm and the fan spins up, as in a game; the Console page shows both.
  • Is it the same as PS5LM Plus?PS5LM grew from PS5LM Plus, the native GPU app by abhi245y, and now lives under its own title ID, PPSA99575, so the two install side by side.
  • Which model for coding agents?A smaller model with a long context: prompts are read several times faster. docs/CLI.md has the trade-offs.
  • Can several consoles run one model?Experimentally, with the fleet build, a separate zip. A PC runs the controller and each PS5 holds a run of one dense llama or qwen2 model's layers on its GPU. So far one PS5 has served a model together with a PC. RPC has no authentication, so keep it on an isolated network: docs/FLEET.md.
  • Can I see inside the model?If you turn it on. POST /v1/introspect returns the logits where you ask, the top candidates and one layer's activations, and can zero, scale or add to a channel. It is off by default, under Settings > Developer: docs/INTROSPECTION.md.
